## 使用示例

### 加载插件
```typescript
const pluginManager = new PluginManager({
  pluginDir: '/plugins',
  extensionsDir: '/extensions'
});

await pluginManager.initialize();
```

### 管理插件
```typescript
// 获取插件列表
const plugins = pluginManager.list();

// 启用/禁用插件
await pluginManager.enable('com.example.plugin');
await pluginManager.disable('com.example.plugin');

// 获取统计信息
const stats = pluginManager.getStats();
```

### 用户界面
```typescript
// 打开插件管理面板
window.zion.commands.executeCommand('zion.showPlugins');
```
