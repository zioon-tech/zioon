## Minimap UX 改进总结

### 已实现的改进：

1) **可调整宽度的拖拽把手**：在 minimap 左侧边缘添加了 6px 宽的拖拽区域，允许用户按需调整 minimap 宽度（60px-600px 范围）
2) **宽度设置持久化**：将用户调整后的宽度保存到 localStorage（键名：zion.minimap.width），重启/刷新后保持用户偏好
3) **动态布局同步**：调整宽度时自动更新编辑器右侧 padding，避免内容被遮挡
4) **视口拖拽功能**：用户可以直接拖拽视口区域来滚动文档，提供类似 VS Code 的交互体验
5) **智能光标反馈**：光标会根据位置自动变化：
   - 在视口区域外：显示为 "pointer"（点击跳转）
   - 在视口区域内：显示为 "grab"（可拖拽）
   - 拖拽过程中：显示为 "grabbing"（正在拖拽）
6) **改进的视觉样式**：视口区域有更好的边框、阴影和悬停效果

### 技术实现细节：

- 使用 `scrollIntoView: true` 确保滚动位置准确
- 拖拽过程中禁用文本选择（`userSelect: "none"`）
- 支持合理的宽度范围限制（60px-600px）
- 与现有功能完全兼容（搜索高亮、诊断标记等）

### 后续优化方向：

- 添加缩放控制选项
- 实现字符级别的精确渲染模式
- 添加 minimap 显示/隐藏动画
- 支持不同的渲染模式（简单/详细）
- 优化超大文件的性能表现
