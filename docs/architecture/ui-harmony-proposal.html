02 · Activity Bar 方案

当前用的是 VS Code 风格的左侧 accent 条。以下是 4 种替代方案。

当前问题

左侧 2px accent 条是 VS Code 的经典做法，但在 Zion 的整体轻量语言中略显突兀。 Activity Bar 背景 (--surface-2) 和 Sidebar 背景区分度不够时，accent 条变成唯一的导航线索，过于刚性。

让选中态更"柔和"：用圆角填充代替硬条，或者把 indicator 做成更精致的圆点/短条。 统一 Activity Bar 图标在 default/hover/active 三态的 opacity 和色值变化。

04b · Multi-Panel 水平滚动

当用户水平分屏（Cmd+\）且总宽度超出视口时，Panel 容器变为水平滚动。 每个 Panel 有最小宽度约束（--panel-min-width: 420px），超出部分通过 scrollLeft 滚动。 焦点切换时自动将 active panel 滚动到可视区域。

分屏方案

滚动策略

Panel 容器 zion-panels-root 添加 .is-horizontal-scroll 类， 设置 overflow-x: auto。每个 Panel 的 min-width 保证内容不被挤压。 容器的 min-width = 列数 × --panel-min-width。

焦点自动滚动

用户点击某个 Panel 获得焦点时，revealActivePanelInScroller() 计算该 Panel 相对容器的位置， 如果不在可视区域内（含 24px margin），则平滑滚动 scrollLeft 到合适位置。

视觉区分

Active Panel 用 border-color: var(--accent) + box-shadow 提示焦点。 非 active Panel 保持安静。Split handle hover 时 accent 高亮。 Trackpad 横向滑动直接滚 Panel 容器。

Split Handle 交互

6px 宽，默认 opacity: 0.58。 Hover/拖拽时 accent 高亮 + opacity: 1。 拖拽比例限制在 0.15 ~ 0.85 防止挤压。 拖拽过程中实时更新 flex 比例。

Active Panel 滚动

Wheel Bridge

在 Panel 内部的表格 / 代码块上横向滚动到底时，滚轮事件冒泡到 Panel 容器继续横向滚动。 installHorizontalWheelBridge 通过 canScrollX() 判断是否还有空间。

Maximize 模式

双击 Panel → maximizePanel()：记录原始比例 → 将路径上所有 split 设为 0.82 / 0.18 → active Panel 占据大部分空间。再次双击 → restorePanelLayout() 恢复。

侧边栏和右侧面板的 header 统一性：标题字号、action button 尺寸、tab 样式。

统一要点

1. Sidebar header 和 Aux bar header 使用相同的 padding (8-10px) 和 title 字号 (13px/600)。 2. Action button 统一 26×26px（sidebar）和 22×22px（aux bar），通过容器区分层级。 3. Aux bar 的 tab 和 Bottom panel 的 tab 用相同的 pill 样式。 4. Header 区域不加背景色，和内容区融为一体；或统一加 --surface-2 做轻区分。

搜索框

Session manager 的搜索建议做成 inline 风格：高度 28px，圆角 --r-md， 左侧 search icon + placeholder，右侧可选 clear button。 不做 full-width 占位，而是 flex: 1 在 toolbar 中自适应。

分组标签

对话列表的分组（文件夹/时间）用全大写 + letter-spacing + --fg-faint 色值， font-size 10px，padding 8px 顶部开始。不用加背景色，靠排版节奏区分。

08 · 和谐度检查清单

以下 10 条是整体和谐的"硬指标"，可以逐条对照检查。

① Surface 层级 ≤ 3 层

整个界面最多 3 个明度层级：bg → panel → soft panel。 不要出现第 4 种背景色，否则视觉碎片化。

surface-1 / 2 / 3

② Border 统一低透明度

所有区域分割线用 --border-faint (8% opacity)， 只有需要强调的分界才用 --border-soft (14%)。 不使用硬实色边框。

③ 圆角成体系

icon-btn: 6px → row: 8px → card: 12px → 容器: 16px。 不出现 3px、5px、7px 等非体系值。

④ Icon button 三档

small (22px): tree row inline; medium (26px): toolbar/header; large (28px): editor header。三档尺寸不再随意。

⑤ 选中态策略统一

一级导航 (activity bar) 可以用 indicator；列表行 (session/context/file) 一律用 accent-soft 填充 + 文字 accent 色，不加左条。

⑥ Hover 统一

所有可交互元素的 hover 统一用 --surface-3 背景。 不使用 outline、box-shadow 等其他 hover 效果。

⑦ 字号收敛到 5 档

10px (label/meta) → 11px (tab/secondary) → 12px (body/title) → 13px (section title) → 15px+ (page heading)。去掉 9.5/10.5/11.5 等。

⑧ 状态点统一

streaming = accent 色 + pulse 动画；ready = ok 绿色； idle/error 不加点。点的尺寸固定 6px，不要 4px/8px 混用。

⑨ Shadow 只给浮层

浮层/弹出菜单：--shadow-md；选中 tab "浮出"：--shadow-xs； 其他所有区域不加 shadow。

⑩ 间距节奏

行内 gap：4px (紧凑) / 6px (标准) / 8px (宽松)。 区域 padding：8px (header) / 10px (content) / 12px (section)。 不出现 3px、5px、7px 等中间值。
