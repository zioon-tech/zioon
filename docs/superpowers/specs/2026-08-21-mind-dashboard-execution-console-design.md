# Mind Dashboard 执行中控台设计

## 定位

Mind Dashboard 是基于 Run Ledger 的只读执行中控台，优先回答：

1. 当前什么在运行。
2. 哪些问题需要用户介入。
3. 当前资源消耗是否异常。

## 信息结构

- `实时`：运行中、需介入、今日运行、今日 Token；异常聚合；正在运行；最近完成。
- `资源`：今日、24 小时、7 天范围内的模型 Token、运行次数、失败率、平均耗时和工具调用量。
- `项目`：按 project 来源聚合活跃运行、异常、Token 和最后活动时间。

## 异常规则

- 相同来源和错误类别的重复异常合并，显示次数与最近发生时间。
- 同一来源在异常之后出现成功运行，则旧异常标记为已恢复，不进入默认待介入列表。
- 运行超过 30 分钟仍无完成事件视为停滞警告。

## 交互与视觉

- 保持只读，不提供停止、重试或预算修改。
- 点击运行或异常行打开对应会话；无会话时打开运行日志。
- 删除插件内部重复标题、光晕和厚卡片，改为紧凑行、细分隔线和语义色。
- 红色仅表示未恢复异常，蓝色表示运行，绿色表示成功。

## 性能

- 缓存各 Run 事件，账本变化时重算聚合。
- 三秒时钟只用于刷新运行耗时，不重复读取所有历史事件。
- 数据聚合拆为纯函数模块并覆盖关键测试。
