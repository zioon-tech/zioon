## 问题确认与原因
- 项目为纯 Web/PWA 架构，未集成 Electron 或系统防睡眠能力（见 [package.json](file:///Users/bytedance/Downloads/zion-next/package.json) 与 [README-PWA.md](file:///Users/bytedance/Downloads/zion-next/README-PWA.md#L116-L147)）。
- 任务运行依赖浏览器定时器与事件流（chat.run 生命周期： [registry.ts: __chatRun](file:///Users/bytedance/Downloads/zion-next/src/ext/registry.ts#L1580-L1672)，事件发出 [registry.ts](file:///Users/bytedance/Downloads/zion-next/src/ext/registry.ts#L1636-L1668)；停止 [registry.ts: __chatStop](file:///Users/bytedance/Downloads/zion-next/src/ext/registry.ts#L1681-L1692)）。
- 浏览器在息屏/后台时会节能（定时器限频甚至冻结）。若系统进入睡眠，JS 执行与网络都会暂停，任务随之中断或停滞。

## 目标
- 屏幕熄灭或非激活时，尽量保证任务持续运行；若被中断，可自动恢复与续跑。

## 方案设计
### A. OS 层保持唤醒（macOS）
- 集成 macOS caffeinate：在 chat/runStarted 时启动 `caffeinate -diu`（防止系统因闲置而睡眠与显示睡眠），在 chat/runFinished 或 chat/aborted 时结束。
- 可选用 `-w <PID>` 绑定到运行子进程（若有），确保运行结束自动释放。
- 提供设置开关“保持唤醒（macOS）”，默认关闭，避免不必要耗电。

### B. Web 层屏幕唤醒
- 使用 Screen Wake Lock API：在运行期间申请 `navigator.wakeLock.request('screen')`，在运行结束释放；适用于 Chrome/Safari 新版本。
- 作为跨平台通用兜底：即便无法阻止系统睡眠，至少避免显示睡眠导致的后台冻结。
- 在设置中提供“屏幕常亮（跨平台）”开关。

### C. 运行可靠性与自动恢复
- 利用既有任务面板的自动继续逻辑（[dev.task-panel/main.js](file:///Users/bytedance/Downloads/zion-next/extensions/dev.task-panel/main.js#L390-L411)，[appendUserInstructionAndRun](file:///Users/bytedance/Downloads/zion-next/extensions/dev.task-panel/main.js#L464-L536)），在 runFinished/aborted 时检测未完成项并续跑（[监听处](file:///Users/bytedance/Downloads/zion-next/extensions/dev.task-panel/main.js#L691-L707)）。
- 新增“心跳/超时重试”：运行器在 N 秒无 token 事件时判定停滞并触发一次安全重试（仅当仍有未完成任务）。
- 新增“可见性变化恢复”：监听 `visibilitychange`，若页面从后台回到前台且上次运行被中断，自动触发续跑。

### D. UI 与安全
- 设置页新增两项开关与说明：涉及耗电、隐私与权限提示。
- 状态栏显示当前保持唤醒状态（OS/Web），便于用户随时关闭。
- 日志中记录唤醒开启/释放与自动恢复触发，便于排查。

## 验证与回归
- 用长时任务进行对比测试：
  1) 未开启任何唤醒：锁屏或后台后观察 token 事件暂停；
  2) 开启 Screen Wake Lock：确认显示不息屏、任务持续；
  3) macOS 开启 caffeinate：合盖或息屏下任务持续，运行结束自动释放；
  4) 人为断网/睡眠：恢复后自动续跑是否生效。
- 检查事件流与日志：chat/runStarted、chat/token、chat/runFinished/aborted 顺序是否正确；锁防重入（[__todo_auto_continue_lock](file:///Users/bytedance/Downloads/zion-next/extensions/dev.task-panel/main.js#L468-L487)）是否有效。

## 风险与兼容
- caffeinate 仅限 macOS；Windows/Linux 无法使用该方法，需依赖 Screen Wake Lock 与自动恢复。
- Wake Lock 在部分浏览器版本需要用户交互或权限；失败时回退到自动恢复策略。
- 耗电与散热增加：默认关闭，由用户主动开启。
