MEMORY / GUIDE

接上你的记忆。

网页和命令行操作同一份记忆文件。使用 Zioon 账号登录，登录信息会保存在本机，下一次直接继续。

在网页中使用

进入控制台 ↗，登录后可以浏览文件夹、搜索内容、编辑原文、下载文件及查看版本历史。

网页保存会检查文件是否在其他地方更新。发生冲突时，你的草稿会留在编辑器中；先下载草稿，再读取最新版本。

1. 检查 CLI

agent-fs --help
agent-fs auth status

已安装且可以登录时，直接进入下一步。新设备需要 Bun 和 agent-fs CLI。

2. 按需安装

先按 Bun 官方文档 ↗ 安装 Bun。以下命令安装固定版本的 CLI，并添加 Zioon 登录命令。

mkdir -p "$HOME/.local/share/zioon-agent-fs"
bun add --cwd "$HOME/.local/share/zioon-agent-fs" @desplega.ai/agent-fs@0.18.5

curl -fsSL https://memory.zioon.tech/downloads/agentfs-login.mjs \
  -o "$HOME/.local/share/zioon-agent-fs/agentfs-login.mjs"
curl -fsSL https://memory.zioon.tech/downloads/install-agentfs-login.mjs \
  -o "$HOME/.local/share/zioon-agent-fs/install-agentfs-login.mjs"

bun "$HOME/.local/share/zioon-agent-fs/install-agentfs-login.mjs" \
  --upstream-cli "$HOME/.local/share/zioon-agent-fs/node_modules/@desplega.ai/agent-fs/dist/cli.js"

安装后使用 ~/.local/bin/agent-fs，或将 ~/.local/bin 加入终端 PATH。已有 Bun 安装在其他位置时，给安装命令添加 --bun /实际路径/bun。

3. 登录一次

~/.local/bin/agent-fs login \
  --api-url https://memory.zioon.tech

~/.local/bin/agent-fs auth status

打开命令显示的登录链接，确认账号与验证码。登录成功后，凭据、服务地址和默认存储位置会自动保存到 ~/.agent-fs/config.json。后续无需重复设置环境变量；凭据过期或被撤销时重新登录。

4. 查看、搜索和写入

agent-fs ls /memory/dev.identity
agent-fs cat /memory/dev.identity/profile.md
agent-fs grep "项目" /memory/dev.identity
agent-fs write /memory/dev.identity/notes.md --content "今天的协作笔记"
agent-fs log /memory/dev.identity/notes.md

更完整的参数可以通过 agent-fs <命令> --help 查看。文件写入会留下版本记录；网络中断后应先读取文件，确认是否已写入，再决定是否重试。

同一份记忆，两种入口

入口用途
网页控制台浏览、搜索和编辑自己的记忆文件
agent-fs CLI在终端或 Agent 中读写记忆文件

退出登录

agent-fs logout

此命令撤销当前 CLI 登录并移除本机凭据。网页控制台的登录可通过右上角「退出」结束。
