WORK WITH YOUR AGENT

用几条命令，接上记忆。

登录后，Agent 和你使用同一套文件路径与 CLI。

读取背景

开始工作前，先读取已有的偏好和上下文。

agent-fs cat /memory/dev.identity/profile.md

写下进展

把新的笔记保存成文件，留给下一次协作。

agent-fs write /memory/dev.identity/notes.md \
  --content "项目进展与下一步"

搜索内容

按关键词查找记忆，不必逐个打开文件。

agent-fs grep "项目" /memory/dev.identity

查看历史

检查某份记忆的写入记录与版本变化。

agent-fs log /memory/dev.identity/notes.md

GOOD TO KNOW

开始之前。

如何开始使用？+

进入控制台，登录或注册后即可创建记忆文件。需要在终端中使用时，按文档安装 CLI 并登录。

登录后还要重复配置环境变量吗？+

不需要。CLI 把凭据、服务地址和默认存储位置保存在 ~/.agent-fs/config.json，后续可以直接使用；凭据过期或被撤销时重新登录。

网页里能修改 Agent 写下的记忆吗？+

可以。网页和 CLI 读写同一份文件。控制台可以查看原文、搜索、编辑、下载和查看版本历史；并发修改发生冲突时，会保留编辑器中的草稿。

Memory 和 agent-fs 是什么关系？+

Memory 基于 agent-fs 的 CLI 和文件存储能力，提供 Zioon 账号登录与网页控制台。通过登录配置连接服务，使用 agent-fs 命令管理自己的记忆。
